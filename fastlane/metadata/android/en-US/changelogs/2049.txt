SwiftFloris now installs under its own application ID (io.github.sysadmindoc.swiftfloris), ending the install collision with upstream FlorisBoard and unblocking F-Droid inclusion. Upgrading from 1.8.x is a one-time reinstall: export a backup on the old install, install 1.9.0 alongside it, restore the archive (old-ID and upstream FlorisBoard backups are accepted as same-vendor), re-enable the keyboard, then remove the old app. Obtainium users must re-subscribe with the new ID.
