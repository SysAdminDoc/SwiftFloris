# SwiftFloris — Deep engineering audit (2026-05-29)

Aggressive correctness / security / reliability / UX pass over the whole tree
(`:app` + `:lib:*`). Method: a fast local source mirror was searched by a
multi-agent finder workflow (11 subsystem + 2 cross-cutting auditors), every
finding was re-verified against the live source at the byte level, and only
high-confidence, behavior-preserving fixes were applied.

> **Build/verification caveat.** This working host has **no Android SDK**
> (`ANDROID_HOME` empty, `local.properties` `sdk.dir` is a placeholder), so the
> gradle build gates **could not be run here**. Every change below was verified
> by static reasoning + re-reading the live code. **Before release, run on a
> host with the SDK:**
> `./gradlew :app:verifyNoInternetPermission :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`
> No hard invariant (no-INTERNET, Apache-2.0, encrypted-dict, FLAG_SECURE) was
> touched. No new dependency or string resource was added (Crowdin-safe).

## Applied fixes (19)

### Security / DoS
1. **PBKDF2 iteration count uncapped on decrypt** — `ime/dictionary/EncryptedDictionaryExport.kt`.
   A crafted `.sfexp` could set `iterations` to `Int.MAX_VALUE` (~2.1 B), hanging
   the device on import before the GCM tag is checked. Added `MIN_PBKDF2_ITERS`
   (100 000) / `MAX_PBKDF2_ITERS` (10 M) bounds, enforced on both decrypt and encrypt.
2. **Unbounded attribute-range expansion** — `lib/snygg/.../SnyggRule.kt`.
   A theme (untrusted `.flex`) with `key[code=0..2000000000]` materialized one
   string per integer → OOM at theme load. Added `MAX_ATTR_RANGE_WIDTH` (65 536)
   cap + `toIntOrNull` overflow guard; absurd/unparseable ranges are skipped.

### Resource leaks / lifecycle
3. **Glide point-buffer leak + stuck state** — `ime/text/keyboard/TextKeyboardLayout.kt`
   `onGlideCancelled()`. `glideDataForDrawing.clear()` + `isGliding = false` were
   gated on the `showTrail` pref, but the buffer is populated regardless. With
   glide on + trail off the buffer grew unbounded for the session and `isGliding`
   latched `true`. Moved the state reset out of the pref branch.
4. **`MediaMetadataRetriever` never released** — `ime/clipboard/ClipboardInputLayout.kt`.
   A native extractor + FD leaked for every video thumbnail rendered/recomposed.
   Wrapped in `try/finally { release() }`.
5. **Mutex left locked on cancellation/throw** — `ime/nlp/NlpInlineAutofill.kt`.
   `setterGuard.lock()/unlock()` without `try/finally`; a cancellation between
   them froze all later inline-suggestion updates for the process. Switched both
   methods to `withLock { }`.
6. **MCP `ServiceConnection` leak** — `ime/mcp/McpServiceConnectionManager.kt`.
   When `bindService()` returns false the connection was never unbound (Android
   contract violation); the bounded rebind loop leaked one per attempt. Added
   `unbindService` on the false path.

### Correctness
7. **Keyboard iterator dropped rows after an empty row** — `ime/text/keyboard/TextKeyboard.kt`.
   `hasNext()` returned false at the first zero-key row (`keyIndex < 0`), silently
   excluding all later rows from hit-testing/glide. Now skips empty rows + throws
   `NoSuchElementException` past the end.
8. **Glide trail drawn when disabled** — `ime/text/keyboard/TextKeyboardLayout.kt`.
   The live-trail/highlight draw block ignored `glideShowTrail`. Gated on it.
9. **Signing fingerprint used the superseded cert under key rotation** —
   `app/settings/about/SigningFingerprint.kt`. Single-signer branch returned
   `signingCertificateHistory` (oldest→newest) and the caller took `.first()`
   (the original cert), inconsistent with the multi-signer branch. Now prefers the
   current `apkContentsSigners`. (Identical for all non-rotated packages today.)
10. **Smart-compose window split surrogate pairs** — `ime/smartcompose/SmartComposeContextWindow.kt`.
    The hard-cap `substring` could begin on an orphaned low surrogate (emoji/astral
    tails). Advances the start index past a leading low surrogate.
11. **Unbalanced `beginBatchEdit` on early return** — `ime/editor/AbstractEditorInstance.kt`
    `finalizeComposingText`. The early `return false` skipped `endBatchEdit()`,
    leaving the editor in a nested batch (suppressed `onUpdateSelection`). Moved
    `beginBatchEdit()` after the guard.
12. **Adaptive-touch refinement no-op for UNSPECIFIED keys** — `ime/text/keyboard/AdaptiveTouchModel.kt`.
    `refine()` keyed the primary lookup by `computedData.code` while everything
    else uses `touchModelCode()`; the lookup missed when they diverge. Unified.
13. **Language detector misclassified accented Latin** — `ime/translate/LanguageDetector.kt`.
    `LATIN` was ASCII-only, so `é à ñ ü …` counted as `UNKNOWN` and could win the
    dominant-script vote → translation suppressed. Extended LATIN ranges to
    Latin-1/Extended-A/B + Latin Extended Additional, and excluded `UNKNOWN` from
    the dominant-script selection.
14. **`commitChar` could request a negative composing-region start** —
    `ime/editor/AbstractEditorInstance.kt`. Added `coerceAtLeast(0)`.
15. **Empty emoji-history migration entry** — `app/AppPrefs.kt`. `split(";")` on an
    empty pref produced a bogus `Emoji("")`. Filter blanks.

### Concurrency
16. **Cross-thread visibility of `PressedKeyInfo.job`/`blockUp`** — `ime/input/InputEventDispatcher.kt`.
    Written by the long-press coroutine without the lock, read under the lock.
    Marked `@Volatile` so a long-press up-suppression can't be missed.

### Robustness / UX / accessibility
17. **Backup "Cancel" deleted the live workspace mid-write** — `app/settings/advanced/BackupScreen.kt`.
    Added `enabled = !isBackupInProgress` (mirrors RestoreScreen).
18. **Manual-export sync target lost its grant on process death** — `app/settings/sync/SyncSettingsScreen.kt`.
    Added `takePersistableUriPermission` (the folder channel already did this).
19. **Sync channel rows: double a11y target, no radio role** — `app/settings/sync/SyncSettingsScreen.kt`.
    Switched to the house `rippleClickable(role = Role.RadioButton)` + inner
    `RadioButton(onClick = null)` pattern (mirrors `BackupScreen.RadioListItem`).
20. **Extract-view parent unchecked cast** — `ime/landscapeinput/ExtractedInputRootView.kt`.
    `parent as LinearLayout` threw `ClassCastException` on the OEM-fallback branch.
    Changed to `parent as? ViewGroup`.
21. **CJK candidate NaN confidence** — `ime/cjk/CjkInputProvider.kt`. Explicit
    `!confidence.isNaN()` check for a clear error from an out-of-tree provider.

## Verified-clean (notable false positives)

- **`ZipUtils.isUnsafeEntryName` "rejects spaces" / "missing NUL check"** — flagged
  by 3 finders but **false**: the source contains a literal `\u0000` (NUL) char in
  the `contains(...)` call, which the file-reader renders as a blank. The NUL check
  is correctly present and there is no space rejection. (A follow-up to replace the
  raw NUL byte with the `'\u0000'` escape for editor-safety is worthwhile but was
  not applied — matching an invisible byte via tooling was too error-prone to risk.)

## Deferred — real but need device verification or a larger change

These are credible findings left for a focused, device-backed pass (do **not**
fix blind):

- **Bidi `VisualLogicalReorderer.logicalToVisual` wrong order for mixed-level text**
  (`ime/bidi/VisualLogicalReorderer.kt`) — sorts runs level-ascending instead of
  UAX#9 L2; also `String.reversed()` corrupts supplementary-plane RTL + combining
  marks. Fix = use `java.text.Bidi.reorderVisually` + grapheme-aware reversal. **P1,
  needs bidi test fixtures.**
- **`ClipboardMediaProvider.query` discards the ORIENTATION cursor** and the backing
  DAO query `SELECT (:projection)` binds a column name as a *value*
  (`provider/ClipboardMediaProvider.kt`, `provider/ClipboardDatabase.kt`) — two
  interacting bugs; the naive fix returns wrong data. Needs the DAO query rewritten
  + a device paste test. **P2.**
- **`DictionaryImporter` per-archive entry cap bypassed** — `MAX_IMPORTED_ENTRIES`
  is enforced per-file, not across `found` in `parseZip` (up to ~12.8 M entries).
  Fix = thread the running count through the parsers. **P2.**
- **`ClipboardFileStorage.cloneUri` uses `nanoTime()` as the file id** → possible
  collision/overwrite. Fix = `AtomicLong`/row-id. **P2.**
- **Share-intent backup never closes its workspace** (`BackupScreen.kt`) — leaves the
  plaintext zip in cache and reuses a stale archive. **P2.**
- **`VoiceCommandExecutor.removeItemFromList` mutates the transcript buffer before
  the editor edit** → permanent buffer/editor desync on failure. Needs a
  snapshot/restore. **P2.**
- **`HardwareKeyboardRuntimeMapper` seeds the candidate set with the raw Android
  keyCode**, colliding with macOS virtual codes → wrong char for some `.keylayout`
  imports. **P2, needs hardware-keyboard test.**
- **`DictionaryManager` DAO used after Room close** during a personal-dictionary
  toggle race (`runCatching` masks it on the async paths; `forgetWord` is exposed).
  **P2.**
- **`AdaptiveTouchModel.persist()` JSON-encodes on the input thread every 8 taps**
  (`recordTap` runs on the UI thread). Move encode/write off-thread. **P2 perf.**
- **`PersonalBigramStore`/`PersonalTrigramStore` `tablesByLocale` HashMap** mutated
  under one monitor, iterated under another → possible CME. Use `ConcurrentHashMap`.
  **P3.**
- **`PersonalDictionaryImportBatch` infers inserted rows by table diff** → Undo can
  delete words the user learned during the import. Use the DAO's returned insert ids.
  **P3, data-loss risk — handle carefully.**
- **`SymSpellIndex` distance-2 delete-form generation** gates recursion on first
  insertion, missing some distance-2 candidates. **P3.**
- **`LdmlTransformsParser.consume` skips all single-char transforms** when the
  longest rule is 1 char (`maxLookback < 2`). **P3.**
- **`TranslationRouter` drops inter-sentence whitespace** when stitching translated
  pieces. **P3.**
- **`NlpInlineAutofill` leaks `InlineContentView`s inflated after the 2 s latch
  timeout.** **P3.**
- **`FlorisImeService` rebuilds `resourcesContext` on duplicate locale emissions**
  (`distinctUntilChanged` the mapped pair). **P3.**
- **`SubtypeManager.switchToNext/PrevSubtype` falls to `Subtype.DEFAULT`** when the
  active subtype isn't in the list. **P3.**
- **`ClipboardManager.close()` cancels only the cleanup job**, leaking the history
  flow collector (`ioScope.cancel()` instead). **P3, close() rarely called.**
- **`StickerMediaProvider.openFile` opens an arbitrary decoded `content://` URI**
  without allow-listing against held SAF grants. **P3, grant-scoped.**
- **Clipboard image/video items have no `contentDescription`** (TalkBack). Needs
  new localized strings (deferred to avoid Crowdin churn). **P3.**
- **`Native.NativeStr.toJavaString()` ignores buffer offset/position** on the
  `hasArray()` path (latent — no caller yet). **P3.**
- **`CrashUtility` `readFile` in `uncaughtException` lacks an IO guard.** **P3.**
- **`DictionaryPackDescriptor` asset paths don't reject `..`** — not exploitable
  (read via `AssetManager` namespace, not the FS) but worth adding for consistency.
- **`AddonManifest` fingerprint regex `^[0-9A-F:]{95}$`** is looser than
  `AddonSigningPinSet`'s strict pattern; unify on the strict validator. **P3.**
- **`AndroidMcpClient` response cap compares UTF-16 char length to a byte cap** —
  bounded already by the kernel's binder limit. **P3.**
