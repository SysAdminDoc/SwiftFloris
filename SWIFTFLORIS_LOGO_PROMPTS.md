# SwiftFloris Logo/Icon Prompts

## About SwiftFloris
SwiftFloris is a premium, fast, and intuitive Android keyboard app inspired by SwiftKey, built on FlorisBoard's proven backend. The app focuses on speed, accuracy, and elegant typing experience.

## Logo Requirements
- **Format**: PNG image
- **Background**: TRANSPARENT (no background color, use RGBA with alpha channel)
- **Dimensions**: 512x512px minimum
- **Style**: Modern, minimalist, professional
- **Color Palette**: Primary accent color with depth and sophistication
- **Suitability**: Must work at small sizes (48px) and large sizes (512px)

## Tips for Generation

### When Using Midjourney
```
/imagine prompt: [Select one prompt above] --niji 6 --ar 1:1 --quality 2 --style raw
```

### When Using DALL-E
- Set image size to 1024x1024 or higher
- Save as PNG with transparency
- Request "transparent background" explicitly

### When Using Stable Diffusion (with transparency)
- Use model with transparency support (e.g., Clipdrop, Remove.bg)
- Generate at 768x768 or 1024x1024
- Post-process to ensure clean alpha channel

### After Generation
1. Save all 5 results as PNG files
2. Verify transparent background (should show checkerboard pattern in editor)
3. Crop to clean boundaries, keeping transparent padding
4. Test at small sizes (48x48) and large (512x512)
5. Select top 3 candidates for app conversion
