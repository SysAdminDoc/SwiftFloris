# SwiftFloris Logo/Icon Design Prompts

**Requirements**: Transparent PNG, no background, professional keyboard app aesthetic

---

## Prompt 1: Minimalist Swift + Keyboard Hybrid
```
A minimalist app icon featuring a stylized keyboard key shape integrated with a flowing swift/arrow motif. The key is modern and geometric, primarily in sleek silver-blue gradient (#4A90E2 to #89B4FA). A swift bird or arrow flows through or around the key in a complementary accent color (purple #9B59B6). Ultra-clean lines, 3mm stroke, 512x512px, transparent background PNG, no drop shadow or depth effects, flat design, professional app store quality.
```

---

## Prompt 2: Modern Keyboard with Flourish
```
Clean, modern app icon of a keyboard viewed from 45-degree angle, with one key highlighted in bright accent color. The keyboard is a sleek dark blue-gray silhouette. A flowing, elegant swoosh or flourish emerges from the highlighted key in bright magenta/purple (#FF79C6). Minimal detail, premium feel, 512x512px transparent background PNG, icon-style design, perfect for Android app launcher.
```

Abstract app icon showing a single keyboard key in motion, with motion lines or a trailing effect suggesting speed and responsiveness. Geometric, modern, flat design, 512x512px, transparent PNG, no background, suitable for high-DPI Android displays.

The "S" uses a gradient from deep blue (#5E81AC) to bright blue (#89B4FA). Optionally incorporate a subtle keyboard outline or row of key dots beneath. ## Design Specifications

- **Format**: PNG with transparency (RGBA)
- **Size**: 512x512 pixels (scalable for adaptive icons)
- **Background**: Fully transparent
- **Color Palette**:
  - Primary Blue: #4A90E2, #5BA3F5, #89B4FA, #7AA2F7
  - Secondary Purple: #9B59B6, #BB9AF7, #CBA6F7
  - Dark Blue: #5E81AC, #1A2B5F
  - Accent: #FF79C6, #7DCFFF
- **Style**: Flat, minimalist, modern, premium
- **No Effects**: No drop shadows, no depth, no gradients that need smoothing

## How to Use These Prompts

1. **Option A - Midjourney**: Paste each prompt into Midjourney with `--no-bg` flag
   ```
   /imagine [prompt] --no-bg --ar 1:1 --q 1
   ```

2. **Option B - DALL-E 3**: Use prompt directly in ChatGPT or DALL-E, request "transparent background"

3. **Option C - Stable Diffusion**: Use with `--s` flag for style consistency
   ```
   [prompt] --transparent-bg --size 512x512
   ```

## Post-Generation Steps

1. Generate all 5 variations
2. Select top 3 candidates
3. Refine background transparency (remove any traces of alpha)
4. Export as PNG with full transparency
5. Test on Android launcher for appearance
